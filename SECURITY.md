# Security Policy

## Supported versions

| Version | Supported |
| ------- | --------- |
| 0.2.x   | yes       |
| < 0.2   | no        |

## Reporting a vulnerability

Please report security issues privately by emailing **mertcobanov@gmail.com** with a description, reproduction steps, and impact. Please do not open public GitHub issues for security reports.

You will receive an acknowledgement within 7 days. Fixes will be coordinated and released as patch versions.
